# BrowserSwitcher

Мини-приложение для строки меню macOS: быстро меняет браузер по умолчанию.

- Иконка в строке меню — текущий браузер по умолчанию
- Клик — меню со всеми установленными браузерами
- Прокрутка колёсиком над иконкой — переключение по кругу

## Сборка

```bash
./build.sh
open BrowserSwitcher.app
```

Нужны только Command Line Tools (swiftc). При смене браузера macOS может один раз показать системное подтверждение.
